# 夜霜 A 股复盘

**FrostyNight A-share Review**

一个面向 A 股收盘复盘的工作区，将市场回顾、板块观察、个股走势和个人复盘记录放在同一条阅读路径中。

[访问夜霜复盘](https://frostynight.top/stocks/)

## 可以做什么

- **按日、周、月回看市场**：围绕所选日期浏览行情摘要、板块表现与公开专题。
- **整理板块与个股观察**：按名称、代码或板块查找，结合证券详情查看行情和风险提示。
- **查看历史走势**：按需载入截至所选日期的近期日 K、成交量和逐日行情，保留来源与缺项说明。
- **回访过往观察**：查找历次公开记录，区分当时观察、后来补录与事后回顾。
- **管理个人关注**：登录后维护自己的关注列表、操作复盘和账户设置。
- **适配不同阅读场景**：支持桌面与手机浏览，并提供键盘导航。

## 从哪里开始

1. 进入「市场复盘」，选择要回看的日期或周期。
2. 从板块或个股进入详情，结合当日行情与历史走势阅读。
3. 需要保留自己的观察时，登录后进入「我的」。

公开市场页面可直接浏览；个人功能需要登录，新用户通过邀请码注册。具体内容以页面显示的数据日期与可用状态为准。

## 产品关注的细节

- 保留分析日期与资料来源，让不同时间的判断可以回溯。
- 对缺失数据和补录内容明确标注，不用空值冒充结果。
- 个人关注与个人复盘记录按账户隔离。
- 将市场事实、观察记录与后续反馈分开呈现。

## 仓库范围

本仓库用于产品介绍。产品源码、选股规则、评分参数、策略研究方案、内部研究记录和账户数据不在公开范围内。
